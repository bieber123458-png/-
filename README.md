## 我的記帳本 `money-book.html`

個人記帳 App（單一 HTML 檔，資料只存在瀏覽器本機）。

- **明細**：記錄支出、收入、轉帳／還款；金額可直接輸入算式（如 `120+35`）；每月結餘、預算進度、搜尋
- **資產**：淨資產與 6 個月走勢；現金、銀行、存款、股票、創業等資產帳戶（可直接校正成最新市值）
- **負債追蹤**：信用卡、房貸、車貸、學貸等；利率、每月還款、繳款日倒數、還款進度與預計還清時間
- **規劃**：存錢目標（可連結帳戶餘額或手動存入，算出每月需存多少）、願望清單（30 天冷靜期、換算成幾天生活費、買了直接記帳）
- **分析**：分類圓餅圖、排行、每日走勢；消費診斷（儲蓄率、月底預估、與前 3 個月比較、小額消費、週末消費、緊急預備金、負債比，並給出健康分數）
- JSON 備份／還原、匯出 CSV（可用 Excel 開啟）、深色模式

手機用 Safari／Chrome 開啟後「加入主畫面」即可當 App 使用。
